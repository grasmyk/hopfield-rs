To make the network work properly, you should install MNIST dataset, and insert it to '/data' folder that you can create in your project. 
All links of data that you need to insert:
 - https://www.google.com/search?q=https://storage.googleapis.com/cvdf-datasets/mnist/train-images-idx3-ubyte.gz (Картинки для обучения)
 - https://www.google.com/search?q=https://storage.googleapis.com/cvdf-datasets/mnist/train-labels-idx1-ubyte.gz (Метки для обучения)
 - https://www.google.com/search?q=https://storage.googleapis.com/cvdf-datasets/mnist/t10k-images-idx3-ubyte.gz (Тестовые картинки)
 - https://www.google.com/search?q=https://storage.googleapis.com/cvdf-datasets/mnist/t10k-labels-idx1-ubyte.gz (Тестовые метки)
